1. Project Title
Smart Library Management System
2. Description
This is a simple Python-based library management system.
It helps to manage books in a library.
The user can add, view, search, issue, and return books.
It also calculates the fine for late book returns and saves the book data in a JSON file.
3. Features
Add new books
View all books
Search books by title
Issue books
Return books
Calculate late return fine
Save book data
Load saved book data
Handle invalid input
Simple menu-based system
